# AI Code Evaluation & Reasoning Benchmark

An automated framework designed to benchmark and score AI-generated Python code based on syntactical correctness, documentation, and logic rubrics.

## Features
- **Syntax Validation:** AST-based syntax checking for safe validation.
- **Rubric Scoring:** Standardized 100-point scoring model across syntax, documentation, and algorithmic logic.
- **Error Flagging:** Isolates syntax and runtime faults for systematic model benchmarking.

## Tech Stack
- Python 3.x (`ast`, `json`)
